### 👋 Обо мне

Занимаюсь разработкой **Telegram-ботов** и **бэкенд-автоматизацией** на Python и JS —
от простых чат-ботов до систем с базой данных, уведомлениями и веб-интерфейсом (Mini App).

Сейчас учусь на программиста, прохожу стажировку и выполняю первые заказы —
каждый проект в репозиториях ниже написан вживую, с реальной архитектурой, а не «для галочки».

- 🔭 Сейчас делаю: Telegram-боты с CRM-логикой и парсингом данных
- 🌱 Изучаю: продвинутый Python (FastAPI, SQLAlchemy), JS
- 💬 Открыт к первым заказам и стажировкам
- 📫 Связаться: [Telegram](https://t.me/AxsionTM)
