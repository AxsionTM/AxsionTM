## Обо мне

Разрабатываю **Telegram-ботов** и системы автоматизации на Python и JavaScript — от небольших ботов до проектов с базами данных, уведомлениями, API и веб-интерфейсами.

Сейчас учусь на программиста, прохожу стажировку и развиваю собственные проекты. Большинство репозиториев ниже — реальные проекты, в которых я самостоятельно занимаюсь разработкой и архитектурой.

- Сейчас работаю над: Telegram-ботами, CRM и автоматизацией
- Изучаю: Python, FastAPI, SQLAlchemy и JavaScript
- Интересуюсь: backend-разработкой и автоматизацией
- Открыт к стажировкам и первым коммерческим проектам
- Связаться: [Telegram](https://t.me/AxsionTM)
